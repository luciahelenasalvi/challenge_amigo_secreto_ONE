## Descrição do Projeto "Amigo Secreto"

### Visão Geral
Este projeto é uma aplicação interativa desenvolvida para facilitar a organização e o sorteio de amigo secreto entre participantes. O sistema permite inserir nomes, validar entradas e sortear automaticamente um amigo secreto para cada pessoa inscrita.

Desenvolvido por Lúcia Helena Aparecida Rissi Salvi,  a partir do desafio Oracle Next Education | G9.

### Funcionalidades
1.	**Tela inicial** exibe o título principal e orientação para a digitação dos nomes dos amigos participantes. 
2.	**Cadastro de participantes** a partir de um campo de texto para inserção do nome e um botão para adicionar o nome à lista de amigos. Em caso de tentativa de adicionar campo vazia, exibe a mensagem: “Digite um número válido”. 
3.	**Administração da lista** em que o usuário pode visualizar a lista atualizada a cada nome inserido. 
4.	**Sorteio automático** com o botão “Sortear amigo” com uma mensagem do resultado do sorteio. 

### Projeto original
"Neste desafio, você desenvolverá uma aplicação que permita aos usuários inserir nomes de amigos em uma lista para, em seguida, realizar um sorteio aleatório e determinar quem é o "amigo secreto".
O usuário deverá adicionar nomes por meio de um campo de texto e de um botão "Adicionar".
Os nomes inseridos serão exibidos em uma lista visível na página, e ao finalizar, um botão "Sortear Amigo" selecionará um dos nomes de forma aleatória, exibindo o resultado na tela".

**Link**: :https://github.com/Oracle-Next-Education/challenge-amigo-secreto_pt

### Sugestão de melhorias
Outros tipos de vadidação, como: não permitir a inserção de números e normalizar o nome escrito (transformar em primeira maiúscula e demais minúsculas).
Botão reiniciar o jogo.
